# VideoDecode

YMM4 の動画読み込みプラグインです。倍速再生で表示されないフレームのデコードを省きます。仕組みと計測結果は[ルートの README](../README.md) にあります。

標準の FFmpeg 読み込みは、倍速再生で飛ばすフレームもすべてデコードしてから捨てます。VideoDecode は、飛ばすフレームのうち他のフレームから参照されないものをデコードしません。表示されるフレームの画素は標準と同じです。

## 有効にする方法

YMM4 の設定の「プラグイン」の画面から、「VideoDecode (非参照フレームのスキップ)」を FFmpeg より上に移動してください。並べ替えるまでは使われません。

## 対象の素材

次の条件をすべて満たす素材だけを扱います。それ以外は標準の FFmpeg 読み込みに任せます。

- mp4 または mkv に入った H.264 / HEVC
- 8bit 4:2:0、SDR、プログレッシブ、回転なし
- GPU でハードウェアデコードできる

## ParallelRender と併用したとき

ParallelRender は出力範囲をチャンクに分けて並列に描画します。チャンクの先頭がキーフレームから遠いと、そこまで余分にデコードすることになります。VideoDecode は動画のキーフレームの位置を ParallelRender に知らせ、余分なデコードが少なくなる位置にチャンクの境界を置かせます。

## 制限

- 倍速でない区間では、省けるフレームがほとんどないので速くなりません。

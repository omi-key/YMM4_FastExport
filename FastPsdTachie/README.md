# FastPsdTachie

YMM4 の立ち絵プラグインです。インストールすると、「PSD立ち絵 (高速化版)」という立ち絵の種類が加わります。仕組みと計測結果は[ルートの README](../README.md) にあります。

標準の「PSD立ち絵」は、有効なレイヤーが前のフレームと同じでも、毎フレームすべてのレイヤーを調べ直して合成し直します。FastPsdTachie は合成済みの画像を使い回すので、レイヤーの多い PSD ほど速くなります。パラメーターと設定画面は標準と同じです。

## 使い方

YMM4 で、キャラクターまたは立ち絵アイテムの立ち絵の種類を「PSD立ち絵 (高速化版)」に変えます。

- 変えるとパラメーターが初期化されることがあるので、PSD とレイヤーの選択を確認してください。
- 既存のプロジェクトは、bat でまとめて切り替えられます ([ルートの README](../README.md#3-立ち絵を高速化版に切り替える))。

## 標準との違い

まばたきのタイミングが違います。標準は YMM4 を起動するたびに変わりますが、FastPsdTachie はいつも同じタイミングにします。

## 制限

- 初めて出てくるレイヤーの組み合わせは、標準と同じだけ時間がかかります。
- YMM4 の更新で標準の立ち絵の処理が変わると、見た目が標準とずれる可能性があります。
